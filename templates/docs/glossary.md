# Glossary

> **This file is a template.** Delete this banner and the example when you customise.

Terms that mean something specific in this project, and ordinary words used precisely.

Two things earn an entry: a domain term a newcomer would not know, and — more importantly — a common
word this project uses in a narrower sense than usual. The second kind causes the misunderstandings,
because nobody thinks to look it up.

Definitions live here once. Every other document links rather than re-defining.

---

**Term** — what it means here, in one or two sentences. Where the project's usage is narrower than
the ordinary meaning, say what it excludes; that is usually the useful half.

**Term with a rejected synonym** — the definition. Note the word this project deliberately does
*not* use for it, and why, if a reader is likely to reach for it.
